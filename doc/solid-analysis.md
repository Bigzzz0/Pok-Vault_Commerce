## สรุปการตรวจสอบตามข้อกำหนด (Compliance Checklist)
- [x] **Single Responsibility**: แยก Controller / Service / Repository / Entity / DTO ไม่ปะปนกัน
- [x] **Open/Closed**: ขยาย Discount Strategy และ Order State ได้โดยไม่ต้องแก้ if-else เดิม
- [x] **Liskov Substitution**: State ทุกตัวสลับแทนกันได้ใน Context โดยไม่เกิดพฤติกรรมผิดเพี้ยน
- [x] **Interface Segregation**: ทุกโมดูลแยก Interface เฉพาะทาง ไม่มี Fat Interface
- [x] **Dependency Inversion**: Controller ➔ Service Interface ➔ Repository Interface และใช้ Constructor Injection เท่านั้น
- [x] **การระบุไฟล์และบรรทัด**: ระบุตำแหน่งไฟล์พาธสัมพัทธ์ (Relative Links) และช่วงบรรทัดจริงในทุกหัวข้ออย่างละเอียด
